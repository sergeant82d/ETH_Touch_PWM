Temperature unit (web page and LCD)
Below the start the fans are off; from the start they run at 20%, rising to 100% at the top. Uses the blended temperature. Also settable from Home Assistant.

Status

--

MQTT

MQTT stays off while the node ID is the factory default. The password is never shown; leave it blank to keep the saved one. The network temperature comes from an HA automation (docs/MQTT.md).

Static address

Changing these restarts the controller; the page moves to the new address.

Time

Clock
Time comes from pool.ntp.org. The offset is fixed (no daylight saving switch).

Firmware

Firmware update (OTA)

Use .pio/build/<board>/firmware.bin. The controller refuses firmware built for the other board, then restarts with the new one (about 30 s). Settings are kept.

Appearance

Custom starts from the NUT colours. Changes show at once; Save keeps them.

Web login

Every change on this page needs the login; viewing doesn't. Forgotten: the settings have to be erased over USB (docs/BOARDS.md).
