Manual override

100%
On: both fans at the set speed instead of the curve (starts at 100%). Never kept over a restart.

Fan channels

UseChannelPWM pinTach pinSpeed
Tick the fans that are connected, in order: the next channel becomes available once the one before it is ticked; only the last ticked one can be unticked. Grey = not available (or not wired on this board).

Fan curve

Temperature unit (web page and LCD)
Below the start the fans are off; from the start they run at 20%, rising to 100% at the top. Uses the blended temperature. Also settable from Home Assistant.

Status

--

MQTT

MQTT stays off while the node ID is the factory default. The password is never shown; leave it blank to keep the saved one. The network temperature comes from an HA automation (docs/MQTT.md).

Ethernet address

Changing this restarts the controller. With DHCP the router picks the address: open the page by the device name (WiFi tab), e.g. http://fancontroller-01.local.

Time

Clock
Time comes from pool.ntp.org. Daylight saving switches automatically (checked at every 5-minute time sync).

Networks

WiFi is a backup: joined when the Ethernet link has been down for 30 s, left 60 s after Ethernet is back. While on WiFi the page is at the WiFi address (or the device name below).

Backup WiFi network

The password is never shown; leave it blank to keep the saved one.

WiFi address

Use a different address from the Ethernet one (both are on your network).

Device name

Open the page at http://--.local on Ethernet or WiFi (most computers and iPhones; some Android phones don't support .local names). Empty = made from the node ID.

Setup hotspot

Starts when no network has worked for 60 s: join it and open http://192.168.4.1. Turns off once Ethernet or WiFi has worked for 30 s. Default password 12345678: change it.

Firmware

Firmware update (OTA)

Use .pio/build/<board>/firmware.bin. The controller refuses firmware built for the other board, then restarts with the new one (about 30 s). Settings are kept.

Appearance

Custom starts from the NUT colours. Changes show at once; Save keeps them.

Web login

Every change on this page needs the login; viewing doesn't. Forgotten: the settings have to be erased over USB (docs/BOARDS.md).
