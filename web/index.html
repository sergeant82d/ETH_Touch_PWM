Fan channels

UseChannelPWM pinTach pinSpeedOffset vs fan 1
Offset: each other fan is held at fan 1's speed plus or minus this many RPM (10 RPM steps, up to 500), by adjusting its own speed a little every second. Needs both fans' tach wires; not used at full speed in the failsafe, or while fan 1 is off. Saved with the Save button below.
Tick the fans that are connected, in order: the next channel becomes available once the one before it is ticked; only the last ticked one can be unticked. Grey = not available (or not wired on this board).

Fan curve

Temperature unit (web page and LCD)
Below the start the fans are off; from the start they run at 20%, rising to 100% at the top. Uses the blended temperature averaged over about 30 s; once on, the fans stop only 2 °F (1.1 °C) below the start, and their speed changes gradually (up to 2%/s faster, 0.5%/s slower). Also settable from Home Assistant.

Status

--

MQTT

The node ID is also the controller's name (LCD, this page, web address). MQTT stays off while it is the factory default. The password is never shown; leave it blank to keep the saved one. The network temperature comes from an HA automation (docs/MQTT.md).

Networks

WiFi is a backup: joined when the Ethernet link has been down for 30 s, left 60 s after Ethernet is back. While on WiFi the page is at the WiFi address (or the device name, System tab).

Ethernet address

Changing this restarts the controller. With DHCP the router picks the address: open the page by the device name (System tab), e.g. http://fancontroller-01.local.

Backup WiFi network

The password is never shown; leave it blank to keep the saved one.

WiFi address

Use a different address from the Ethernet one (both are on your network).

Setup hotspot

Starts when no network has worked for 60 s: join it and open http://192.168.4.1. Turns off once Ethernet or WiFi has worked for 30 s. Default password 12345678: change it.

Firmware

Appearance

Custom starts from the NUT colours. Changes show at once; Save keeps them.

Time

Clock
Time comes from pool.ntp.org. Daylight saving switches automatically (checked at every 5-minute time sync).

Firmware update (OTA)

Use .pio/build/<board>/firmware.bin. The controller refuses firmware built for the other board, then restarts with the new one (about 30 s). Settings are kept.

Device name

Open the page at http://--.local on Ethernet or WiFi (most computers and iPhones; some Android phones don't support .local names). Empty = made from the node ID.

Web login

Every change on this page needs the login; viewing doesn't. Forgotten: the settings have to be erased over USB (docs/BOARDS.md).

Restart

Restarts the controller, the same as its reset button. Nothing is changed or lost: settings, logs and notes stay. Use it after changing hardware, or when something has stopped responding. The fans run on the fan curve again about 5 seconds later; this page reconnects by itself in about 20 seconds. On the LCD: gear icon, then hold Restart for 2 seconds.

Factory reset

All settings go back to the factory values: login, name, MQTT, network (DHCP), WiFi, fans, fan curve, time zone. The controller restarts into the Setup page; find it by the IP on its LCD or in your router, or at http://fancontroller-xx.local. The theme, the notes and the SD card logs are kept.
